C64 DPainter - Changelog
========================

A paint program for Commodore 64 bitmap pictures (multicolor and hires)
for Windows 11, macOS (Apple silicon and Intel) and Linux.


Version 1.0
-----------

The first full version. Thank you to everybody who tried the betas and
sent ideas!

About
- A little firework left and right of the icon in Help > About.

Better import (compared with Retropixels)
- Automatic contrast before converting (each color channel, as the
  "normalize" of Retropixels, or only the brightness).
- Ordered dithering as in Retropixels: the pattern shifts the brightness,
  then the nearest color is taken - calm, regular patterns instead of
  scattered dots. The cell colors are chosen from the patterned picture.
- Error diffusion without stray colors: the cell colors come from the
  picture itself and the spread error is limited.
- New dithering: blue noise, Yliluoma (2 colors) and a cell pattern that
  sits on the 4 x 8 color cells.
- Presets: Recommended (Bayer 4x4, YUV, best fit, automatic contrast -
  the new default), Retropixels look, Smooth and Sharp.
- The same improvements for hires and hires free imports; the PETSCII
  converter got the automatic contrast too.
- The presets are shown as four small previews of your picture - one
  click picks the look you like best.

Side border sprites (experimental)
- Layer > Side border sprites opens the side border of a multicolor
  picture: left and right of the picture there is a strip of 12 x 200
  multicolor pixels made of 10 sprites per side. Each 12 x 21 block has
  its own color, multicolor 1 and 2 are shared, transparent pixels show
  the background color.
- Dots, freehand, lines, curves, shapes, fill, airbrush, eraser and the
  color picker paint into the strips; a new side panel section sets the
  shared colors. Projects keep the sprites, the PNG with border shows
  them.
- File > Export > C64 program with side border (.prg) and ACME source
  with side border (.asm): a cycle-exact viewer with a stable raster and
  a sprite multiplexer that opens the border in every line (PAL only,
  checked in VICE x64sc).

Safety and comfort
- Crash recovery: changed pictures are saved quietly every minute. After
  a crash the next start offers to restore them; a normal quit removes
  the files.
- The import settings are kept for the next start (the picture
  adjustments start at 0 for every new image).
- The window opens where it was last time, with the same size (macOS and
  Windows also the position; Linux the size).
- Export PNG 640 x 400 and 1280 x 800 (2x / 4x larger, sharp pixels) for
  showing pictures on the web.
- README and release notes explain how to open the program the first
  time on Windows, macOS and Linux.

Graphics modes: hires and hires free
- At the start and with File > New a window asks for the mode:
  Multicolor (160 x 200, 4 x 8 cells, background + 3 colors), Hires
  (320 x 200, standard bitmap mode, 8 x 8 cells with 2 colors) or Hires
  free (320 x 200, all 16 colors without rules).
- Hires follows the rules of the standard bitmap mode; empty pixels show
  the paper color. A third color in a cell is blocked, replaces the
  rarest color or uses the nearest one, as in multicolor.
- Hires free has no color limits and marks nothing; cells with more than
  two colors are reduced to their two most frequent colors only when the
  picture is exported for the C64.
- All tools, layers, selection, text, gradients and the import work in
  hires (the converter makes hires or hires free pictures). Auto dither
  and the dither brush stay multicolor only.
- New file formats: Art Studio hires (.art) and Doodle (.dd), load and
  save; a hires C64 program (.prg) with its own viewer; projects keep the
  mode.

Perspective
- Selection > Perspective handles (also in the side panel and the
  transform window): six handles on the corners and edges. Top/bottom
  (corners move left/right) or left/right (corners move up/down);
  "Opposite" moves the other corner of the edge the other way, "Free"
  moves every corner on its own; the middle handles move a whole edge.
- Brushes > Brush as selection puts the brush into the picture to
  transform (and distort) it.

Layers
- "Protect other layers on clashes" (Layers panel, Layer menu): when a
  cell is full, only colors of the active layer may be replaced.

Font editor
- Hires or multicolor character sets: background $D021, multicolor 1
  $D022, multicolor 2 $D023 and the character color (0-7); keys 0-3 choose
  the drawing color, C switches the mode. Multicolor import, project
  files and ACME export with all colors.

Text fields
- Click into a text to place the cursor, select with the mouse or
  Shift+arrows, Home/End, Delete, Ctrl+A (text tool, test text, built-in
  file window).
- macOS: the open and save panels are opened after the click is finished,
  so the name field of the save panel takes clicks again; an Edit menu
  brings Cut/Copy/Paste/Select All to the panels.

Version 0.99 beta
-----------------

macOS for Intel
- There is now also a macOS version for Macs with an Intel processor.
  The downloads are named C64DPainter-macOS-Silicon.zip (M chips) and
  C64DPainter-macOS-Intel.zip.

Auto backup
- New option Options > Auto backup (every 3 minutes). It is off at every
  start of the program.
- When it is on, the picture is saved every 3 minutes into the working
  folder as "Backup.c64dp" - always in the C64 DPainter project format,
  with all layers and the template. When the spare page is used, it is
  saved as "Backup (page 2).c64dp" too.
- A backup is only written when the picture has changed; the file is
  overwritten each time.

Recent files
- The File menu lists the last 8 files you opened or saved. A click opens
  the file again; files that no longer exist are removed from the list.
  "Clear list" empties it.

More file formats
- Open now also reads Advanced Art Studio (.ocp) and Amica Paint (.ami)
  multicolor pictures (format details from RECOIL by Piotr Fusik). They
  are only read: save the picture as project, KLA, PNG or PRG.

My brushes
- The ready-made stamp silhouettes were removed.
- "My brushes" stays: a window (toolbox button or Brushes > My brushes)
  with all brushes saved in the "brushes" folder of the working folder.
  The chosen brush becomes the brush and the tool switches to Dots.

Sprite editor (new, menu Tools)
- A full-window editor for up to 64 sprites in the look of the PETSCII
  editor. Every sprite is hires (24 x 21) or multicolor (12 x 21) with its
  own color; multicolor 1 and 2 and the background are shared.
- Tools: pencil, line, rectangle, filled box, fill; mirror left/right,
  overlay of a second sprite, flip, shift, invert, copy/paste, expand X/Y,
  undo/redo. Alt+click picks, right button paints transparent.
- Sprite list with add, duplicate, delete and move; preview at 1x/2x and
  an animation preview (range, speed, ping-pong).
- Import from the multicolor picture or a 320 x 200 image: place the
  frame, or take a whole raster of sprites (columns, rows, gap), hires or
  multicolor, background and shared colors automatic or chosen.
- Project files (.c64sprites); export ACME assembler source with all
  colors, flags and animation settings, raw BIN (64 bytes per sprite)
  and PNG. "Use as brush" hands a multicolor sprite to the painter.
- View > Sprite grid (24x21) and a Sprite 24x21 preset in the grid
  settings for drawing sprites in the multicolor editor.
- Ideas from Spritemate, MagSpriteEd and Sprite Studio 64 (all MIT).

Font editor (new, menu Tools)
- A full-window editor for C64 character sets (256 hires characters),
  starting with the C64 font.
- Tools: pencil, line, rectangle, fill; tiles 1x1, 2x1, 1x2, 2x2
  (neighbors or quarters layout), flip, rotate, invert, shift, copy/paste,
  back to the original ROM character, compare with the ROM, inverse half
  (128-255), test text.
- Import from the multicolor picture, a 320 x 200 image or the C64 font
  (upper/lower case): cells are read row by row into the chosen
  characters.
- Project files (.c64font); open raw character sets (.bin/.64c); export
  ACME assembler source, raw BIN and PNG.
- Ideas from KANJI and the C64 BDF font editor (both MIT).

PETSCII editor (new, menu Tools)
- A full-window editor for PETSCII pictures (C64 text mode: 40 x 25
  characters from the character ROM, one color per character, a common
  background). Close it to get back to the multicolor editor.
- Convert the multicolor picture or any image into PETSCII: character set
  upper/lower case, all characters / no letters / blocks only, inverted
  characters, color matching, brightness, contrast and background.
- Tools: draw, colorize, character only, eraser, brush (copy a rectangle
  and stamp it), text input; Alt+click picks, Shift draws straight lines,
  Alt+arrows shift the screen, undo/redo, grid.
- Character selector with a dropdown for the arrangement: Standard PETSCII
  (always first), sorted by shape (Petmate), letters & digits, lines &
  frames, blocks & shades, curves & symbols.
- Save and open Petmate files (.petmate); export PRG (runnable viewer),
  ACME assembler source (.asm) and PNG.
- Ideas from Petmate (nurpax, MIT), petsciirender (gnacu), PETSCII editor
  (Marq / ventti, WTFPL) and Image-to-PETSCII (amb, idea only). The
  characters are the original C64 character ROM (c) Commodore.

Text tool (new, toolbox and Brushes > Text)
- Writes text in multicolor pixels and turns it into the brush.
- Fonts: C64 wide (8x8, the C64 characters with wide pixels), C64 tall
  (8x16) and Narrow (an own 3x7 font that fits one cell).
- Upper or lower case, letter spacing, several lines, shadow or outline
  in a second color - never more than two colors per cell.

Gradient fill
- Custom ramps: the last ramp of the 3-, 4- and 5-color tabs is your own.
  Click its color fields and choose the colors; they are saved and come
  back after a restart. The Shade brush can use them too.

Swap colors
- A color can now be replaced by the background color (its pixels become
  %00). The background itself still cannot be replaced.
- New toolbox button with an icon for the cell color swap brush.

Import & convert (ideas from Retropixels by Michel de Bree)
- Color matching: choose how "the most similar color" is measured -
  RGB (as before), YUV, XYZ, Lab, OkLab or brightness only.
- Cell colors: Best fit (as before), Most frequent (the three most
  frequent colors of each cell) or Same in all cells (the background plus
  the same three colors in the whole picture - good for game graphics).
- New help page "Import & convert".

Auto dither and Dither brush
- Color matching can be chosen too; it decides which allowed color
  replaces a color in a full cell.

Layers
- Changed stacking: layer 2 is now at the bottom, layer 3 above it and
  layer 4 on top. The list stays 1 - 4 from top to bottom. Projects saved
  with 0.96 are converted on loading so they look the same.

Side panel
- Click a section title (Brush, Patterns, Colors, Layers, Cell under the
  mouse, Navigator and the tool sections) to fold it in and out. At every
  start all sections are open.

Fixes
- Saving a Koala picture with the system save dialog could create a name
  like "picture.kla.kla". Doubled extensions are now removed, and the
  macOS save dialog no longer adds the extension twice.
- "Use as brush" on a selection: color 2 (chosen with the right mouse
  button in the palette) is now transparent in the brush, as in Deluxe
  Paint.

About
- New section in the help page "About": "Why This Software Is Free for
  Personal Use".
- RECOIL and Retropixels added to the sources.


Version 0.96 beta
-----------------

Layers
- A picture has four layers: layer 1 is the template for tracing,
  layers 2 to 4 are paint layers, listed from 1 at the top to 4 at the
  bottom in the order they lie on top of each other (layer 2 in front,
  layer 4 at the back).
- The multicolor rules apply to all paint layers together (hidden layers
  included), so every combination of visible layers is always a valid C64
  picture. The cell info marks colors that only come from hidden layers.
- Switch "Layers 3 + 4" next to the Layers title (also in the Layer menu).
  At the start only layer 2 is active and layers 3 and 4 are off.
- Keys 2 / 3 / 4 choose the layer to paint on. All tools, the selection,
  Auto dither, the Dither brush and Smear work on the active layer.
- Each page (spare page) has its own layers.

Eraser (W)
- Makes pixels of the active layer transparent again. "Clear layer"
  empties the whole active layer.

Project files (.c64dp)
- Keep all layers with their visibility, the active layer and the
  template. KLA, PNG and PRG contain the visible layers merged; the
  program warns before layers would get lost.

Gradient fill (Shift+F)
- Fills the connected area under the mouse with a color gradient.
- Gradient window with five tabs: 27 three-color ramps (light -> dark),
  14 four-color and 13 five-color ramps, and the three-color ramps as
  five bands (dark -> light -> dark, light -> dark -> light). A note
  explains the C64 cell color rule for 4- and 5-color gradients.
- Shapes Linear, Circle and Diamond. Single click: from the click point to
  the far edge of the area (linear in one of 8 directions); click and
  drag: direction and width.
- Options: Reverse colors and Dithered transitions (25 / 50 / 75 %).

Shade brush (Shift+W)
- Lightens (left button) or darkens (right button) the colors under the
  brush by one step, once per stroke. Steps: all colors by brightness or
  one of the 3-, 4- or 5-color ramps.

Symmetry (Shift+X)
- Paint mirrored left <-> right, top <-> bottom or four-fold, with movable
  axes. Works with all painting tools, shapes and fills.

New shapes
- Square (N), Triangle (I), Hexagon (O) and Star (L), outlined and filled
  (with Shift). New icons; the rectangle icon is clearly wider than the
  square icon.

Views
- Mirrored view (Shift+M): only the view is mirrored, painting keeps
  working.
- CRT preview window (Shift+V): floating, live while painting, 100 % and
  200 %, CRT look (scanlines, soft picture, PAL color bleed) on or off.

Selection
- Dragging a selection moves a copy; with Shift the original is cut out.

Working folder and quick save
- The working folder is asked for at the start and with File > New; the
  save and open dialogs start there.
- F2 saves a numbered PNG (picture_0001.png ...) into the working folder.

Brushes menu
- Load and save brushes as PNG with a transparent background, selection
  as brush, standard brush, flip / rotate / resize, own colors.
- Stamps window with ready-made silhouettes and "My brushes".

Other changes
- Key 0 fits the picture to the window.
- About window: supported systems, a thank-you to all users (with a red
  heart) and a full list of sources with thanks; Multipaint added to the
  inspirations.
- macOS: built for Apple silicon (M chips) only.
- Windows 11 is the supported Windows version (Windows 10 may crash).


Version 0.95 beta
-----------------
- Dither styles reduced to Artist, Scanlines, Checker and Stripes.
- New dither style "Color": shades by dithering with a darker color that is
  already in the 4x8 cell (or fits into a free slot). Auto dither darkens
  towards darker neighbors, the Dither brush darkens what you paint over
  (Darkness 25 / 50 / 75 %).
- Auto dither and the Dither brush are marked as experimental.
- New Smear brush (Shift+S): drags the colors along the stroke like a
  smudge tool, with a strength setting; full cells use the nearest cell
  color, so the multicolor rules always hold.
- New dithering engine: stepped transitions like pixel artists do it -
  two colors per transition, a few clean stages (50 %, 25 %, 12 %),
  outlines, thin lines and small details stay sharp, only color pairs that
  artists really mix are blended. New settings: Width, Steps, Keep edges,
  Details, Artist pairs.
- Help and README updated.


Version 0.9 beta
----------------
- New Edit > Auto dither (Shift+A): blends the borders between flat color
  areas, with a live preview (dithered / original / split / changes), for
  the whole picture or the selection.
- New Dither brush (Shift+D): the same, only where you paint, with a
  preview of the pixels it would change.
- Dither styles reconstructed from 16 hand-pixelled C64 pictures.
- Color pair affinities measured from the pictures ("color ramps").
- Cell color modes Keep / Add / Re-choose; Add never causes color
  conflicts.
- Help pages, README and version updated.


Version 0.8 beta
----------------
The first public version.
- Strict multicolor rules: 160 x 200 pixels, 4 x 8 cells, bit pairs
  %00 / %01 / %10 / %11. When a cell is full the program can block the
  pixel, replace the rarest cell color or use the nearest cell color.
- Tools: dots, freehand, line, curve, fill, airbrush, rectangle, circle and
  ellipse (each outlined or filled), select and color picker.
- Round, square and diamond brushes from 1 to 16 pixels, plus custom
  brushes made from a selection.
- 42 patterns (density steps, dots, lines, diagonals, grids, textures).
- Swap colors in the whole picture or with a cell brush.
- Selections can be moved, copied, flipped, rotated by 90 degrees or
  freely, scaled and sheared.
- Zoom from 1x to 32x, configurable grid (8 x 8 by default), pixel grid
  and C64 border.
- Only the 16 C64 colors, with 116 palette variants from c64gfx.com;
  "B" marks the background color in the palette.
- A template layer (PNG/BMP/JPG/GIF, above or below the picture, with
  opacity) and a spare page.
- Import & convert for 320 x 200 images with live multicolor preview,
  color adjustments and 13 dithering methods.
- Loading: KLA/KOA, PNG, BMP. Saving: KLA, PNG (320 x 200, 160 x 200,
  384 x 272 with border) and PRG (a runnable C64 program with a viewer).
- Detailed built-in help (F1), light and dark theme, interface size
  100 / 200 / 300 %, movable dialog windows.
