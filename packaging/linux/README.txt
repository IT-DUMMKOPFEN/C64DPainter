C64 DPainter for Linux
======================

Start directly:      ./c64dpainter
Install for you:     ./install.sh   (adds a menu entry and an icon)

Works on any 64-bit Linux desktop with X11 or Wayland (through XWayland).
No libraries need to be installed. If zenity (GNOME) or kdialog (KDE) is
present, their file dialogs are used, otherwise a built-in file browser.

Settings: ~/.config/C64DPainter/settings.json
